# 跟踪微分器

离散 fHan TD：`h` 为实际积分周期，`h0 = max(n, 1) × h` 为最速函数内部预测周期。函数内的 `d = r h0`、`d0 = h0 d`、`y = x1 + h0 x2` 和线性区除数均使用 `h0`；状态按旧 `x2` 更新 `x1`，再更新 `x2`。`r` 对应加速度上限（输入量单位/s²），`max_x2` 对应跟踪值变化率上限（输入量单位/s）。

`td_init()` 遇到无效 `dt/r/n/max_x2` 时把实例置于不可运行状态，`td_update()` 随后保持当前输出。`n < 1` 会钳至 1；`max_x2 = 0` 表示不限速。使用前应把 `td_reset()` 设置为当前实际参考值，避免从零突跳。

给 `x2` 额外加速度限制、对异常数值做保护后，不能声称保留原始 fHan 的严格最速与无超调性质。主机测试只核对离散公式和典型阶跃；上板噪声与周期抖动仍需验证。

公式核对参考：[fHan-TD 论文中的式 (1)–(2)](https://www.nature.com/articles/s41598-025-34362-z)、[带独立预测周期的 TD 论文](https://repository.essex.ac.uk/16081/1/Robotica-V33-N6-2016-Zhang.pdf)。
