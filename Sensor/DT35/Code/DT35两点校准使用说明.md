# DT35 两点校准使用说明

适用工程：`DT35(CubeMX)(V2)`，相关代码位于 `User/Application/Src/my_tasks.c` 顶部的宏定义区。

## 0. 预热

接好电路后，给 DT35 **预热 30 秒**，待输出稳定后再进行校准，否则标定参数会随温漂产生偏差。

## 1. 进入按键校准模式

代码中取消注释 `my_task()` 内的校准采样语句，并烧录：

```c
sample = AdcCalibSample(30000);   // 连续采样 30 s 并返回平均码值
```

烧录后 DT35 进入按键校准模式，`AdcCalibSample(30000)` 会对 ADC 原始码值做 30 秒平均。

## 2. 标定 Near 点（近端）

1. 设置好 **Q2near**（DT35 近端示教位置），将被测物置于近端位置，并**刚性固定 DT35**，避免标定过程中位置变动。
2. 通过调试器查看 `sample` 的值，填入宏定义 `TEACH_NEAR_ADC`。
3. 用尺子测量此时被测物到 DT35 的真实距离，填入宏定义 `TEACH_NEAR_MM`。

```c
#define TEACH_NEAR_MM    100.0f    /* DT35 near 点真实距离 (mm) */
#define TEACH_NEAR_ADC   2416      /* DT35 near 点平均码值（AdcCalibSample(30000) 实测） */
```

## 3. 标定 Far 点（远端）

设置好 **Q2far**（DT35 远端示教位置）后，重复第 2 步：查看 `sample` 的值填入 `TEACH_FAR_ADC`，测量真实距离填入 `TEACH_FAR_MM`。

```c
#define TEACH_FAR_MM     900.0f    /* DT35 far 点真实距离 (mm) */
#define TEACH_FAR_ADC    61789     /* DT35 far 点平均码值（AdcCalibSample(30000) 实测） */
```

> 标定完成后，注释掉 `sample = AdcCalibSample(30000);`，恢复正常测距流程。

## 4. 可选：模拟电流值换算（USE_Q2）

- **不需要查看 DT35 输出的模拟电流值**：将 `USE_Q2` 改为 `0` 即可，距离直接由两点 ADC 码值线性插值计算：

  ```c
  DIST = TEACH_NEAR_MM + (adc_mean[0] - TEACH_NEAR_ADC) * (TEACH_FAR_MM - TEACH_NEAR_MM) / (TEACH_FAR_ADC - TEACH_NEAR_ADC);
  ```

- **需要查看 DT35 输出的模拟电流值**：将 `USE_Q2` 改为 `1`，电路中还需**外接万用表**（串入 DT35 模拟电流输出回路）测量电流：
  1. 设置好 **Q2near** 后，读取万用表电流值，填入宏定义 `I_NEAR_MA`；
  2. 设置好 **Q2far** 后，同理读取电流值填入 `I_FAR_MA`。

  代码将据此建立"电流—码值"线性关系（增益系数 `GF_T`），先算出电流 `Q_2`，再由两点电流插值得到距离：

  ```c
  #define I_NEAR_MA        3.99f     /* DT35 near 点实测电流 (mA) */
  #define I_FAR_MA         19.99f    /* DT35 far  点实测电流 (mA) */
  ```

  ```c
  Q_2  = I_NEAR_MA + GF_T * (adc_mean[0] - TEACH_NEAR_ADC);
  DIST = TEACH_NEAR_MM + (Q_2 - I_NEAR_MA) * (TEACH_FAR_MM - TEACH_NEAR_MM) / (I_FAR_MA - I_NEAR_MA);
  ```

## 5. 标定参数汇总

| 宏定义 | 含义 | 获取方式 |
|---|---|---|
| `TEACH_NEAR_MM` | Near 点真实距离 (mm) | 尺子实测 |
| `TEACH_FAR_MM` | Far 点真实距离 (mm) | 尺子实测 |
| `TEACH_NEAR_ADC` | Near 点平均码值 | 调试查看 `AdcCalibSample(30000)` 的 `sample` |
| `TEACH_FAR_ADC` | Far 点平均码值 | 调试查看 `AdcCalibSample(30000)` 的 `sample` |
| `USE_Q2` | 是否启用电流换算 | 0：直接码值插值；1：先换算电流再算距离 |
| `I_NEAR_MA` | Near 点实测电流 (mA) | 万用表实测（仅 `USE_Q2 == 1` 时需要） |
| `I_FAR_MA` | Far 点实测电流 (mA) | 万用表实测（仅 `USE_Q2 == 1` 时需要） |
