# DT35 采集整条链路说明

适用工程：`DT35(CubeMX)(V2)`。

整条链路为：

```
DT35 模拟电流 (4-20 mA, 333 Hz)
  → 运放 I/V 转换 (0.1 V ~ 2.4 V)
    → ADS8864 (16 位 SAR ADC, 3 线 CS 有忙指示模式)
      → SPI + EXTI 中断读取码值 (理论 66.6 kHz)
        → 32 点滑动平均 (adc_mean[0])
          → 两点标定线性计算 Q_2 / DIST
            → 串口轮询输出
```

---

## 1. DT35 输出模拟电流（333 Hz）

DT35 激光测距传感器以 **4-20 mA 模拟电流**形式输出测量结果，电流更新频率 **333 Hz**。距离与电流成正比：近端对应 4 mA，远端对应 20 mA。

## 2. 运放电路：电流 → 电压（4-20 mA → 0.1 V ~ 2.4 V）

采集板前端由 **AD8606** 精密运放构成 I/V 转换电路（原理图左半部分）：

- DT35 电流从 `DT35 VIN` 端子流入，流经采样电阻 **R25 = 120 Ω (0.1%)**，经 D5/D2 二极管钳位保护后进入运放；
- 运放与 R19（5.11 k）、R28（1 k）、R29（124 k）构成增益网络，**Vref** 由另一路 AD8606（R15/R16/R17 分压 + C20 滤波）提供基准；
- 转换关系（原理图注释）：

```
Vo = I × R25 × (1 + R28 / (R19 || R29)) − Vref × R28 / R19
```

最终 **4 mA ~ 20 mA 对应 0.1 V ~ 2.4 V**（测试点 TP1），送入 ADS8864 的 AINP/AINN 差分输入。

## 3. ADS8864：电压 → ADC 码值（核心时序，理论频率计算）

ADS8864 为 16 位、400 kSPS SAR ADC，SPI 接口。本设计采用 **3 线 CS 有忙指示模式**（时序见上级目录 `Docs/ads8864.pdf` P22），与 STM32F302 的连接：

| ADS8864 | STM32F302 | 作用 |
|---|---|---|
| CONVST | PB15（TIM15_CH2 PWM） | 转换启动脉冲 |
| DOUT | PB14（SPI2_MISO） | 数据输出（同时兼作忙指示） |
| SCLK | PB13（SPI2_SCK） | SPI 时钟（9 MHz） |
| DIN | PB12 | 3 线 CS 模式下固定拉高 |
| DOUT（复用） | PB2（EXTI2 IRQ） | 忙指示下降沿触发中断 |

### 3.1 定时器配置（TIM15，72 MHz，PWM 输出）

- 时钟 72 MHz，**PSC = 0**，1 个计数 = 1/72 MHz ≈ **13.9 ns**；
- **ARR = 1079** → 周期 T = (ARR + 1) × 13.9 ns = 1080 × 13.9 ns ≈ **15000 ns = 15 µs**；
- **CCR2 = 28** → CONVST 高电平脉宽 = 28 × 13.9 ns ≈ **389 ns**。

### 3.2 单次转换时序

1. **TIM15_CH2 拉高（CONVST 上升沿）**：ADS8864 开始一次转换。转换时间 t_conv = **500 ns ~ 1300 ns**（逐次转换、随温度电压漂移）。
2. **CCR2 = 28（约 389 ns）保证忙指示必定出现**：脉宽 389 ns 小于 t_conv 最小值 500 ns，因此无论本次转换何时结束（EOC），CONVST **必然已经回到低电平**——按 ADS8864 规则，EOC 时 CONVST 为低 → 输出忙指示，工作模式彻底确定，不会随机丢失忙指示。
3. **转换完成**：DOUT 首先输出 **1 bit 忙指示**（一个下降沿），该下降沿同时出现在 PB14（MISO）和 PB2（EXTI2），触发 MCU 的 **IRQ 中断**。
4. **中断处理（冻结定时器方案）**：进入 `ADS8864_ReadValue()` 后先**冻结定时器**（`CLEAR_BIT(TIM15->CR1, TIM_CR1_CEN)`，CONVST 保持当前电平、计数停止），随后通过 SPI2 读回 16 bit 数据存入 `adc_rawdata`。SPI 理论耗时：

```
t_SPI = 16 bit ÷ (72 MHz / 8) = 16 ÷ 9 MHz ≈ 1778 ns ≪ T = 15000 ns
```

   读完后再**恢复定时器计数**（`SET_BIT(TIM15->CR1, TIM_CR1_CEN)`），定时器从冻结点继续走完剩余计数。

### 3.3 理论采样频率

由于 SPI 读取时间（约 1.8 µs）远小于定时器周期，且中断期间定时器被冻结、一个周期只处理一次中断，因此**定时器每运行一个完整周期（15000 ns）恰好获取一次 ADC 码值**：

```
f = 1 / T = 1 / 15000 ns ≈ 66.6 kHz
```

即 STM32 获取一次 ADC 码值的理论频率为 **66.6 kHz**。冻结方案还保证采样间隔均匀（每个周期定时器实际运行时间恒为 ARR+1 个计数），且冻结期间天然满足 ADS8864 的采集时间 t_ACQ 要求（SPI 读取与采样保持电容采集重叠进行）。

> 注：原理图上 f_spi = 9 MHz 的注释按"无忙指示、纯 CS 模式"估算的理论最大采样率（239.46 kSPS），与本工程实际采用的"忙指示 + 冻结定时器"方案不同，以 66.6 kHz 为准。

## 4. 码值缓存与 32 点滑动平均

- 每次中断读到的 16 bit 码值按 `adc_counter` 依次存入环形缓冲区 **`adc_rawdata[ADC_SAMPLE_SIZE]`（32 个）**，存满后从头覆盖；
- 主循环调用 `Mean_filter()`，用 CMSIS-DSP 的 `arm_mean_q31()` 对这 32 个数据求平均，结果赋给 **`adc_mean[0]`**，作为当前滤波后的码值；
- 滤波后输出速率 ≈ 66.6 kHz ÷ 32 ≈ **2 kHz**，对 4-20 mA 这类缓变过程量已足够。

## 5. 两点标定线性计算 Q_2 与 DIST

`my_task()` 主循环根据标定时实测的距离、ADC 码值和电流值做线性计算（标定方法见 `DT35两点校准说明.md`）：

- **`USE_Q2 = 1` 时**：先由两点电流与两点码值建立线性关系，把当前码值换算为模拟电流值 `Q_2`（mA），再由两点电流与两点距离插值得到距离 `DIST`（mm）：

```c
Q_2  = I_NEAR_MA + GF_T * (adc_mean[0] - TEACH_NEAR_ADC);
DIST = TEACH_NEAR_MM + (Q_2 - I_NEAR_MA) * (TEACH_FAR_MM - TEACH_NEAR_MM) / (I_FAR_MA - I_NEAR_MA);
```

- **`USE_Q2 = 0` 时**：不经过电流中间量，直接由两点码值插值得到距离：

```c
DIST = TEACH_NEAR_MM + (adc_mean[0] - TEACH_NEAR_ADC) * (TEACH_FAR_MM - TEACH_NEAR_MM) / (TEACH_FAR_ADC - TEACH_NEAR_ADC);
```

## 6. 串口轮询输出

- `getFloatNum()` 把浮点数格式化为字符串，并加帧头 **`'S'`（0x73）**、帧尾 **`'e'`（0x65）**；
- 主循环通过 `HAL_UART_Transmit(&huart1, ...)` **轮询方式从 USART1 发送**（当前工程发送 DIST，保留 4 位小数；`USE_Q2 = 1` 时 `Q_2` 同步计算得出，可按需同样组帧发送），上位机串口助手即可按 `Sxxxx.xxxxe` 格式解析出距离值。
